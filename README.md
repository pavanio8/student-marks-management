# Student Marks Management System

A simple **Student Marks Management System** developed in **C** to manage student records and marks efficiently through a menu-driven console application.

## 📌 Features

- ➕ Add student details
- 📋 Display all student records
- 🔍 Search for a student using Roll Number
- ✏️ Update student details and marks
- 🗑️ Delete student records
- 📊 Automatically calculate:
  - Total marks
  - Average marks
  - Pass/Fail result
- 🚪 Exit the application

## 🛠️ Technologies Used

- **Programming Language:** C
- **Concepts:** Structures, Functions, Arrays, Loops, Conditional Statements, Switch Case
- **Compiler:** GCC
- **IDE:** Visual Studio Code

🧮 Result Calculation

The system calculates:
Total Marks
Total = Subject 1 + Subject 2 + Subject 3
Average
Average = Total / 3
A student is marked PASS if they score at least 35 marks in all three subjects. Otherwise, the result is FAIL.

🎯 Project Objective

The main objective of this project is to create a simple and efficient system for managing student marks while practicing fundamental C programming concepts such as structures, functions, arrays, loops, and file-independent CRUD operations.
